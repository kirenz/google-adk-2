1  Workstation and development tools

The course uses Python 3.12, uv, Git, and Visual Studio Code. The operating system changes terminal syntax and installation details, but the project remains the same. Packages are managed centrally by the root pyproject.toml; separate virtual environments in individual example folders are unnecessary.

1.1 Windows: PowerShell

Visual Studio Code provides the editor and an integrated terminal. Git for Windows provides version control. Git Bash may be installed with Git, but the commands in the Windows sections of this book use PowerShell. Mixing the two shells causes avoidable differences in paths, environment variables, and activation commands.

The official uv installation instructions provide this PowerShell installer:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

The command downloads and executes the official installer. Managed computers may require the institution’s software installation route. After installation, a new terminal is necessary if the current terminal has not received the updated PATH. The following checks establish whether the tools are available:

uv --version
git --version
uv python install 3.12
uv python find 3.12

In VS Code, File → Open Folder opens the course project. Terminal → New Terminal starts a terminal in that folder. A path containing spaces can be passed to PowerShell as a quoted string: Set-Location "C:\Users\student\Documents\google-adk-2". This path is an illustration, not a required personal directory.

1.2 macOS: Terminal or VS Code

Git availability can be checked with git --version. macOS may offer developer command-line tools when Git is missing. uv can be installed using its official macOS installer:

curl -LsSf https://astral.sh/uv/install.sh | sh

The command downloads and executes the official installer. A newly opened terminal picks up the installed executable.

uv --version
git --version
uv python install 3.12
uv python find 3.12

The terminal may use zsh; the basic project commands in this book also work in bash. cd "/path/to/google-adk-2" changes to the project folder. The actual location depends on where the project was downloaded or cloned.

1.3 VS Code and Python

The Microsoft Python extension supplies interpreter selection and Python editing support. After the project environment has been created in the next chapter, Python: Select Interpreter selects the project’s .venv interpreter. On Windows the executable is .venv\Scripts\python.exe; on macOS it is .venv/bin/python.

uv run uses the project environment without manually activating it. This helps keep editor behavior and terminal behavior consistent. A global python command may refer to a different installation, so package checks in this book use uv run python.

1.4 Exercise: diagnose before reinstalling

A short environment report records the operating system, shell, results of the four checks above, and the folder visible in the VS Code terminal. A missing command is investigated by reopening the terminal and checking the official installation instructions before adding another installation.

Expected result: Python 3.12 is available through uv and the terminal is located at the course root.

Success criteria: uv python find 3.12 returns an executable path, both uv and git return versions, and the terminal shows the folder containing pyproject.toml. No Gemini API call or database connection is necessary for this check.
